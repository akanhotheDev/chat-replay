Chat Replay

Scroll a WhatsApp group’s history the way it felt when it was sent — photos, stickers, GIFs and voice notes included.

To install on iPhone: tap Share, then Add to Home Screen.
How to export a chat

Android: open the chat, tap ⋮ → More → Export chat → Include media, then save the .zip file.

iPhone: open the chat, tap the chat name → Export Chat → Attach Media, then save it to Files.

WhatsApp limits exports to about 10,000 messages with media, so very long histories come in pieces. Upload the .zip itself, not a folder.

Everything runs in your browser and your chat is never uploaded.
